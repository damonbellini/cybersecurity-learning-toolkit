# What Is a SOC?

A Security Operations Center is a team and technical capability responsible for monitoring, detecting, investigating, and responding to security events.

## Core functions

- Continuous monitoring
- Alert triage
- Investigation
- Threat detection
- Threat hunting
- Incident response
- Reporting

## Typical SOC workflow

```
Event
  ↓
Detection
  ↓
Alert
  ↓
Triage
  ↓
Investigation
  ↓
Containment
  ↓
Eradication
  ↓
Recovery
  ↓
Lessons learned
```

## Important concepts

**Event:** An observable activity recorded by a system.

**Alert:** An event or group of events that matches a detection condition.

**Incident:** A confirmed security event requiring response.

**False positive:** An alert that appears suspicious but is not malicious.

**True positive:** An alert that correctly identifies malicious or unauthorized activity.
