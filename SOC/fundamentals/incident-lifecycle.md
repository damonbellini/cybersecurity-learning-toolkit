# Incident Lifecycle

A practical incident lifecycle:

1. Preparation
2. Detection
3. Analysis
4. Containment
5. Eradication
6. Recovery
7. Lessons learned

## Example

A suspicious PowerShell execution is detected.

Detection identifies the event.

Analysis determines the command, parent process, user, host, and related network activity.

Containment isolates the affected endpoint if compromise is confirmed.

Eradication removes persistence and malicious artifacts.

Recovery restores normal operations.

Lessons learned improves future detections and response procedures.
