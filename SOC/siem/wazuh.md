# Wazuh

Wazuh is an open source security platform commonly used for endpoint monitoring, log analysis, detection, and security operations.

## Learning objectives

- Deploy a Wazuh lab
- Connect Windows and Linux endpoints
- Collect logs
- Investigate alerts
- Create custom detections
- Understand agents and managers
- Build dashboards

## Lab idea

Create one Windows VM and one Linux VM, install the Wazuh agent where appropriate, generate controlled security events, and investigate the resulting alerts.

Only generate test activity on systems you own or are explicitly authorized to test.
