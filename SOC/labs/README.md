# SOC Labs

This directory contains practical defensive security exercises.

## Lab 1 — Authentication Investigation

Generate controlled failed and successful authentication events in an isolated lab and determine:

- Source
- User
- Host
- Timestamp
- Number of attempts
- Whether the pattern is suspicious

## Lab 2 — Process Investigation

Generate a harmless test process and investigate its process creation telemetry.

## Lab 3 — SIEM

Send endpoint logs into a SIEM and build a dashboard showing:

- Authentication failures
- Successful logons
- Process creation
- Suspicious activity

## Lab 4 — Detection

Write a Sigma rule for a controlled test behavior, validate it against logs, and document false positive considerations.

Only use systems you own or have explicit authorization to test.
