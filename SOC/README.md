# SOC — Security Operations Center

A practical SOC learning path covering monitoring, alert triage, SIEM, detection engineering, threat hunting, and incident response.

## Roadmap

1. SOC fundamentals
2. Alert triage
3. Log analysis
4. SIEM
5. Detection engineering
6. Threat hunting
7. Incident response
8. Practical SOC labs

## Core tools

- Wazuh
- Splunk
- Elastic Security
- Sigma
- YARA
- Windows Event Logs
- Sysmon

## Goal

Build practical defensive security skills by investigating realistic alerts, understanding attacker behavior, and creating repeatable detections.
