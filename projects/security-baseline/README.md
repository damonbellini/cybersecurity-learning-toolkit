# Security Baseline Project

A practical checklist for reviewing the security posture of a small Linux host or lab VM.

## Review Areas

- User accounts and privileges
- SSH configuration
- Network exposure
- Running services
- File permissions
- Logging
- Automatic updates
- Firewall configuration

## Workflow

1. Identify the host and scope.
2. Enumerate users, groups, services, and listening ports.
3. Review authentication and system logs.
4. Check permissions and exposed services.
5. Record findings and prioritize remediation.
6. Recheck the system after changes.

This project is intended for systems owned by the learner or explicitly authorized for testing.
