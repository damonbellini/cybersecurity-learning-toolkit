## Repository Structure

Notes contain study material and learning progress.

Labs contain practical lab notes and templates.

Projects contain small security related projects and scripts.

Tools contains notes and usage references for common security tools.

Cheat sheets contain quick references for commands and concepts.

Writeups contain authorised CTF and lab writeups.

## Ethical Use

Only test systems you own or have explicit permission to assess. Do not use material in this repository to access systems without authorisation.

This repository is a personal learning portfolio. Notes, scripts and lab writeups will be expanded as skills develop.
