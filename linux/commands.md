# Linux CLI Basics

## Navigation

```bash
pwd
ls -la
cd <directory>
cd ..
cd ~
```

## Files and directories

```bash
mkdir <directory>
touch <file>
cp <source> <destination>
mv <source> <destination>
rm <file>
cat <file>
less <file>
```

## System information

```bash
whoami
hostname
uname -a
ip addr
ip route
ps aux
df -h
free -h
```

## Permissions

```bash
ls -l
chmod
chown
```

Use `man <command>` to read the manual.
