# Cloud Security Glossary

## Cognito

AWS service used for identity management and authentication. Cognito can also provide temporary AWS credentials for authenticated or federated identities.

## IAM

AWS Identity and Access Management. Controls which identities can access AWS resources and which actions they are allowed to perform.

## Least privilege

Security principle where an identity receives only the minimum permissions required to perform its task.

## Authorization

The process of determining whether an authenticated identity is allowed to perform a specific action or access a specific resource.

## Temporary credentials

Short-lived AWS credentials that can be issued to an application or identity. Their permissions are determined by the associated AWS identity and IAM policies.

## DynamoDB

AWS managed NoSQL database service used to store structured application data.

## Cloud misconfiguration

A security weakness caused by incorrect cloud configuration, such as excessive IAM permissions, publicly accessible resources or missing authorization controls.
