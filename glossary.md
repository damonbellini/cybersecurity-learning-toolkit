# Cybersecurity Glossary

**Authentication** — verifying who a user or system is.

**Authorization** — deciding what an authenticated identity is allowed to do.

**Hash** — a one-way digest commonly used to verify data integrity.

**Vulnerability** — a weakness that can be exploited or otherwise abused.

**Exploit** — a technique or code that takes advantage of a vulnerability.

**Least privilege** — granting only the access required to perform a task.
