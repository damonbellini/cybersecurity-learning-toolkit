# Encryption

Encryption transforms plaintext into ciphertext using a cryptographic algorithm and key.

## Symmetric Encryption

The same secret key is used for encryption and decryption. It is efficient for large amounts of data.

## Asymmetric Encryption

A key pair contains a public key and a private key. Public key cryptography supports use cases such as secure key exchange and digital signatures.

## Important Concepts

Key management is often more important than the algorithm itself. Study key generation, storage, rotation, certificates, authenticated encryption and TLS.
