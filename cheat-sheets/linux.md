# Linux Security Cheat Sheet

```bash
whoami
id
pwd
ls -la
find / -name filename 2>/dev/null
grep -R "pattern" .
ps aux
ss -tulpn
ip addr
ip route
chmod 755 script.sh
chown user:group file
systemctl status service
journalctl -xe
```

Use commands carefully and understand their effect before running them on important systems.
