# Task 06: Human Oversight and Stop Conditions

## Learning notes
Human oversight is important when evidence is missing, contradictory, or a proposed action could have significant consequences. Retry limits prevent loops and repeated side effects.

## Safe stop conditions
- Required evidence is unavailable.
- A tool fails repeatedly.
- The request exceeds approved scope.
- An action requires approval that has not been granted.

## Practice
Define a maximum retry count and what the agent should report when it is reached.
