# Task 02: Discovery to Design

## Learning notes
Agent design defines expected behaviour before implementation. A written design reduces ambiguity and helps identify risks early.

## Checklist
- State the goal and intended user.
- Describe expected inputs and outputs.
- List assumptions and limitations.
- Identify failure paths before coding.

## Practice
Write a one-sentence goal for a security triage agent and list three things it must not do.
