# Task 03: Role and Scope

## Learning notes
Role describes the responsibility assigned to the agent. Scope defines the boundaries of that responsibility.

## Checklist
- Define allowed tasks.
- Explicitly exclude actions outside the task.
- Set escalation rules for out-of-scope requests.
- Review scope whenever tools or data sources change.

## Practice
Separate investigation and recommendation from direct remediation.
