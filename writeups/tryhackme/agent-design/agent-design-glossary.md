# Agent Design Glossary

## Glossary
- Agent: system that uses a model and possibly tools to pursue a defined task.
- Scope: explicit boundary of permitted work.
- Tool: callable capability exposed to the agent.
- Context: information supplied for the current run.
- State: representation of workflow progress.
- Memory: information retained or retrieved across runs.
- Guardrail: control that limits unsafe or invalid behaviour.
- Human-in-the-loop: person who reviews or approves a decision.
- Structured output: response that follows a defined schema.
- Audit trail: record of actions, inputs, outputs, and decisions.
