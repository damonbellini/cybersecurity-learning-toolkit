# Task 04: Tool Boundary

## Learning notes
Tools determine what an agent can actually do. Least privilege reduces the impact of mistakes or manipulated inputs.

## Checklist
- Prefer read-only tools when possible.
- Restrict targets and arguments.
- Enforce permissions outside the model.
- Log every consequential tool call.
- Require approval for high-impact actions.

## Practice
Explain why a log-reading tool is safer than a tool that can disable user accounts.
