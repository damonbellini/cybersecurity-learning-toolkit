# Task 07: Evidence and Structured Output

## Learning notes
A recommendation should be traceable to evidence. Confidence alone is not proof. When evidence is insufficient, report an explicit unknown or undetermined value instead of guessing.

## Suggested output fields
- finding
- priority
- evidence
- limitations
- requires_human_review

## Practice
Create a sample finding with one evidence item and one limitation.
