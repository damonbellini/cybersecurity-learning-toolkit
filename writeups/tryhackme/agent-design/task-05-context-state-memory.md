# Task 05: Context, State, and Memory

## Definitions
- Context: information available to the model during the current run.
- State: structured workflow progress and current step.
- Memory: information retained or retrieved across runs.

## Example
A log excerpt is context, the current investigation stage is state, and a previously saved approved case summary may be memory.

## Practice
Classify five pieces of information from an agent workflow using these three definitions.
