# Agent Design Flashcards

## Flashcards

**Q: What defines an agent's responsibilities?**
A: Its role and scope.

**Q: What extends an agent's capability?**
A: Tools.

**Q: What tracks workflow progress?**
A: State.

**Q: What is available to the model during a run?**
A: Context.

**Q: What may persist across runs?**
A: Memory, if persistence is implemented.

**Q: What should happen when evidence is insufficient?**
A: State the limitation or mark the result undetermined.

**Q: What should happen before a consequential action?**
A: Apply authorization and required human approval.
