# Cybersecurity Glossary

## Authentication
Verifying who a user or system is.

## Authorization
Determining what an authenticated identity is allowed to access.

## Hash
A one-way function commonly used for integrity checks and password storage schemes.

## Encryption
Transforming data so that it can only be read by someone with the required key.

## Vulnerability
A weakness that can be exploited to affect confidentiality, integrity or availability.

## Exploit
A technique or code that takes advantage of a vulnerability in an authorized testing context.
