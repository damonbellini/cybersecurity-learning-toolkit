# Agent Role and Scope

## Purpose
Define exactly what the agent is allowed to do before implementation.

## Checklist
- State the agent's purpose in one sentence.
- List permitted tasks and explicit exclusions.
- Identify who owns decisions and approvals.
- Define what the agent must do when the request is outside scope.

## Example
An incident-triage assistant may summarize logs and suggest a priority, but must not disable accounts or close alerts.

## Review question
Can a reviewer tell from the specification what the agent must never do?
