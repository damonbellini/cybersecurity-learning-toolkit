# Agent Tool Boundaries

## Principle
Every tool expands the agent's capabilities and potential impact. Grant only the minimum tools needed for the approved task.

## Safer defaults
- Prefer read-only access.
- Limit tools to approved data sources.
- Validate arguments and constrain targets.
- Require human approval for consequential actions.
- Log tool calls and their results.

## Review question
If a tool call goes wrong, what systems or data could it affect?
