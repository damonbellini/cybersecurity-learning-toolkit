# Context, State, and Memory

## Context
Information available to the model during the current run, such as the task, relevant evidence, and instructions.

## State
Structured workflow progress, such as the current step, completed checks, and pending approvals.

## Memory
Information retained or retrieved across runs, when the system is designed to support that.

## Common mistake
Treating these three terms as interchangeable makes workflows difficult to audit and debug.

## Review question
What information is temporary, what records progress, and what persists between runs?
