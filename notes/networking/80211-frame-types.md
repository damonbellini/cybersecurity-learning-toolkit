# 802.11 Frame Types

## Management frames
Beacon frames advertise a network. Probe requests and responses support discovery. Authentication and association frames help establish a connection.

## Control frames
Acknowledgment and request-to-send/clear-to-send frames help coordinate wireless transmission.

## Data frames
Carry data between wireless stations and access points.

## Defensive note
Frame metadata can reveal network behaviour even when payload content is encrypted.
