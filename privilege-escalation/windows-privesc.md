# Windows Privilege Escalation

Windows privilege escalation research focuses on identifying paths from a lower privilege context to a more privileged account or process.

## Areas to Study

Service permissions
Scheduled tasks
Registry permissions
Weak file permissions
Stored credentials
User and group membership
Unquoted service paths
Windows configuration weaknesses

## Methodology

Identify the current user and privileges, enumerate services and scheduled tasks, inspect permissions and configuration, review relevant credentials and security controls, research findings and validate only in an authorised lab.
