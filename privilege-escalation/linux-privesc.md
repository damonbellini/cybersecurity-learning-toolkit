# Linux Privilege Escalation

Linux privilege escalation research focuses on discovering why a low privilege account can reach a higher privilege context.

## Areas to Study

File and directory permissions
SUID and SGID binaries
Linux capabilities
Scheduled jobs
Services
Environment variables
Credentials stored in files
Kernel and package versions

## Methodology

Enumerate the current user and groups, inspect permissions, identify running services and scheduled tasks, review configuration and credentials, research relevant misconfigurations and validate findings in an authorised lab.
