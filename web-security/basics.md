# Web Security Fundamentals

## Topics to learn

- HTTP requests and responses
- Cookies and sessions
- Authentication and authorization
- Input validation
- Access control
- SQL injection concepts
- Cross-site scripting concepts
- CSRF concepts

## Safe lab workflow

1. Use a legal training platform or local lab.
2. Identify the application and its intended behavior.
3. Record observations and reproduce issues safely.
4. Document impact and remediation.

Do not test real systems without explicit authorization.
