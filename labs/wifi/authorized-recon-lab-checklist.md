# Authorized Wi-Fi Reconnaissance Checklist

- [ ] Written permission and scope are documented.
- [ ] Approved SSIDs, BSSIDs, locations, and time window are recorded.
- [ ] Only approved adapters and capture methods are used.
- [ ] No unrelated networks are actively tested.
- [ ] Capture files are stored with restricted access.
- [ ] Sensitive identifiers are redacted from reports.
- [ ] Findings include evidence, impact, and remediation.
- [ ] Capture data is securely deleted according to the engagement plan.
