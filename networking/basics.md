# Networking Fundamentals

## Core concepts

IP addresses identify hosts at the network layer. DNS maps names to IP addresses. TCP is connection-oriented and reliable. UDP is connectionless and lightweight.

## Useful commands

```bash
ip addr
ip route
ping <host>
nslookup <domain>
traceroute <host>
```

## Common ports

| Port | Service |
| --- | --- |
| 22 | SSH |
| 53 | DNS |
| 80 | HTTP |
| 443 | HTTPS |

Only test networks and systems you own or have explicit permission to assess.
