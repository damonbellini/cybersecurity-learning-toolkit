# Common Network Ports

| Port | Protocol | Typical service |
| --- | --- | --- |
| 20/21 | TCP | FTP |
| 22 | TCP | SSH |
| 25 | TCP | SMTP |
| 53 | TCP/UDP | DNS |
| 80 | TCP | HTTP |
| 443 | TCP | HTTPS |
| 3389 | TCP | RDP |

Port numbers alone do not prove which service is running. Verify service behavior in an authorized lab.
